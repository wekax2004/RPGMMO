Tibia MMO Patch Notes

v0.3.0 - The Polish Update

October 1, 2026
  • UI Added a dynamic Settings Menu with Volume Slider, Chat Filters, and Graphics toggle!
  • UI Target info panel now appears when you select a mob, tracking its exact health dynamically.
  • UI Added a full-screen "Level Up" celebration overlay with animations.
  • UI You can now press "M" to open the World Map overlay.
  • UI Added an animated Title Screen before login.
  • UI Added an Interactive Tutorial modal that greets level 1 players on their first login.
  • Combat Damage numbers are now much clearer! Critical hits appear in huge gold text, and heals appear in green.
  • Content Terrain variation! Biomes like the Forest and City now feature random flowers and pebbles to break up the grass repeating pattern.
  • Content Dynamic Weather system! You will now encounter snowfall in the mountains, toxic mist in the swamps, and sandstorms in the desert.
  • Engine Added intense screen shake effects when massive boss AoE spells like Meteor Strike are cast!
  • Engine Fixed duplicate keybindings causing abilities to cast twice.
  • Engine Added dynamic Background Music that changes depending on the biome you are standing in!
  • Engine Added unique Sound Effects for casting spells like Fireball, Heal, Freeze, and Multishot!

v0.2.0 - The Graphics Overhaul

September 29, 2026
  • Content Replaced grey boxes with distinct sprites for all playable classes and mobs!
  • UI Completely redesigned the user interface with a sleek dark mode theme, CSS grids, and a stylized paperdoll equipment screen.
  • UI Tooltips have been converted to a custom floating styled box.
